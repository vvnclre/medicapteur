# ProductName

Nom de produit en Michroma capitales, précédé du capteur orange : la barre inclinée du symbole du logo.

- Structure : `<span class="mc-product"><span class="mc-sensor"></span>Win-Pod Wifi <small>Plateforme</small></span>`. Le `<small>` est facultatif.
- Il remplace les logos produits actuels, qui ont chacun une typographie différente. Tous les produits s'écrivent ainsi : WIN-POD WIFI, WIN-TRACK, WIN-TRACK MINI, T-PLATE, T-PLATE 30TH, XT-PLATE, FUSYO, WIN-POSTURO, W-INSHOE, POWERTRACK, MINIPOD.
- Le consommateur fournit le nom exact ; la classe le met en capitales.
