# ProductName

Nom de produit en Michroma capitales, précédé du repère orange aux angles arrondis qui rappelle le symbole du logo.

- Classe : `mc-product` sur un `<span>` ou un titre. Un `<small>` à l'intérieur ajoute la famille de produit en texte courant.
- Il remplace les logos produits actuels, qui ont chacun une typographie différente. Tous les produits s'écrivent ainsi : WIN-POD WIFI, WIN-TRACK, WIN-TRACK MINI, T-PLATE, T-PLATE 30TH, XT-PLATE, FUSYO, WIN-POSTURO, W-INSHOE, POWERTRACK, MINIPOD.
- Le consommateur fournit le nom exact, en capitales ou non (la classe met en capitales).
