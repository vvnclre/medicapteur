# Measure

Un chiffre clé en Sora (style `data-xl`, chiffres tabulaires), précédé d'une ligne de six cellules orange, avec son unité en `ink-muted` et une explication en `small`.

- Structure : `<div class="mc-measure"><b>12 288<span>capteurs</span></b><em>Explication</em></div>`.
- Le consommateur fournit uniquement des chiffres validés par Medicapteurs (voir le référentiel), avec leur unité.
- Trois mesures au plus côte à côte. Pas de chiffres décoratifs.
