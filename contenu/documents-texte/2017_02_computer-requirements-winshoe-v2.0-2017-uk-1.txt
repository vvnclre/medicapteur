       Computer system requirements for Winshoe
                          PC with following processors (CPU) :
Type

                                  - INTEL Core i5 (or higher)
                                  - Tablets running Windows OS (10 S excluded) with Bluetooth
                                  built in
                                  - Macintosh (Apple) are not compatible
                                  - All in one PC are not compatible


                          If you already own a PC or for other configuration : contact us

Operating system          Windows 7, 8, 10 (32 or 64 bits)1 Windows 10 excluded

RAM Memory                4 Go

Hard Drive                128 Go

Display                   1024 x 768 pixels

Webcam (option)                   - Any webcam running at 30 frames per second
(if video option                  - 1 x discrete graphic card
available)                        - 1 USB port

Data backup               1 external Hard Drive (USB)

       This list of requirements is for indicative purpose only and does not guarantee a full compatibility.
