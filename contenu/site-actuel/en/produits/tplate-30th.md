## Texte de la page (verbatim, onglets dépliés)

```text
T-PLATE 30th

T-Plate30th : the advanced T-Plate, a bigger active area foot pressure plate + full options software

Description

T-Plate30 add 50% more active area and a full option software to the standard best seller T-Plate.

T-Plate30 introduces advanced software options such as :

Research parameters and graphs
Specific diabetic visualization
FPI international foot norm
CPEI : Automatic foot pattern detection : pronation, supinator, neutral foot…
automatic division into 2 zones or 10 zones
manual division in 7 zones or 12 zones
DFU prevention : automatic calculation of the level of risk of ulceration for diabetic patient
automatic descriptive report in dynamic ,static and postural analysis

Characteristics

Mechanical Features
Size (Lenght / Width / Height)	710x610x22 mm
Thickness	8 mm
Weight	3,6 kg
Material	Plexyglas
Electronic Features
Sensing area	500 mm * 500 mm
Sensors	Resistive
Sensors size	0.78 mm * 0.78 mm
Number of sensors	4096
Acceptable temperature	from 0 °C to + 60 ° C
Min to Max pressure per sensor	from 0,4 N to 100 N
Sampling rate	100 Hz / 150Hz Wifi
Platform computer interface	USB or Wifi
Power supply	USB wire
Required operation system	Windows Seven, 8,10.11

Options

T-Plate30 is available in 2 models : T-Plate30 USB or T-Plate30 USB + WIFI

Carrying bag

Download T-Plate30th data sheet

Softwares
T-Plate30th software

Static analysis

Static mapping with center of pressure, Max, Average pressure calculations and weight distribution pattern
Wide range of display (Thermographic, Isopressure, 3D…)
Measuring possibilities (length, angle, pressure, area…)
1:1 printing report

Dynamic analysis

Movie and frame by frame mode
Global Dynamic view
Gait line Display
Calculations and curves

Postural analysis

Statokinesigram and Stabilogram
Instability International parameters
(Altuglass positioner in option)

Video

Autosynchronization between pressure and video
Angle and length measuring tool
```
